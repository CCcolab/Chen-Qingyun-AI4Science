# 六氟丙酮第一报：原始实验与科学问题

1960年《Fluorinated ketones》第一报，研究六氟丙酮与醇、有机金属化合物及含活泼氢化合物的反应。历史英译本p647–653七页影印图已取得并逐页核读；以下是依据该英译本的中文科学释读，未取得俄文原刊，尚未作俄英逐句校勘。[公开馆藏，p647起](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n100)

## 原作者与篇目身份

首页署名为I. L. Knunyants、Ch'en Ch'ing-yun（陈庆云）、N. P. Gambaryan，三人列于苏联科学院元素有机化合物研究所同一机构。首页注明俄文原刊为1960年第4期686–692页，原稿提交日期1958-07-26；英译刊页为647–653。原稿提交与发表日期分别登记。作者表没有给出个人角色分工，不能据排列推定贡献比例。[英译本p647首页](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n100)

《陈庆云传》p23、25–26所述师承与合作可作研究背景；p29的首署与保留合作者贡献故事，应关联133卷共轭衍生物论文，不能移作这篇第一报的校样经过或第117491号文书的贡献证明。传记故事、原刊署名和实验记录分别引证。[A01历史成果及合作档案](../content/a01-historical-achievements.v2.json)

## 一、醇加成与缩酮：产物稳定性有区别

**原文观察：**六氟丙酮与醇形成半缩酮，受热可分解回原反应物；进一步转为对称、不对称缩酮后，作者记录了不同的酸、碱及苯胺处理行为。所述缩酮的耐水解行为不能直接套用于半缩酮。[p647讨论与结构式](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n100)、[p650实验段](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n103)

**解释边界：**这组实验说明作者区分了加成产物及其后续稳定性；没有给出平衡常数或速率常数，不能将原条件下的行为扩大为所有含氟缩酮的普遍性质。

## 二、炔基金属加成：构建可继续转化的含氟骨架

**原文观察：**炔基有机镁试剂与六氟丙酮加成得到炔醇；双镁衍生物及后续偶联、与丙酮反应，又分别形成对称或不对称含氟二醇。作者把羰基加成产物继续用于衍生物构建，而非止于单一产物。[p647–648，I–IV结构式](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n101)、[p651相关实验](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n104)

**作者比较与边界：**文中与已有三氟丙酮研究相比较；不同试剂、反应条件和产率不能直接变成相对速率，也没有提供现代反应势垒。这些具体产物与转化属于原作者的实验贡献。

## 三、羟基酮VII：异常裂解及两项衍生物证据

**原文观察：**羟基酮VII热分解得到六氟丙酮与苯乙酮。实验段分别记有六氟丙酮氨基脲腙、苯乙酮二硝基苯腙与已知样品混熔无降点，形成两项产物鉴定证据。[p648讨论与裂解结构图](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n101)、[p651末段混熔记录](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n104)

**作者解释：**作者将这一C–C裂解方向与通常的脱水方向作比较，认为连在双CF₃取代碳上的羟基难以脱除。鉴定链支持所报裂解产物；这种解释仍不是唯一微观路径或量化势垒的证明。

## 四、β-羟基酸与酯：可转化，也保留未成功的方向

**原文观察：**Reformatskii型反应得到β-羟基酯VIII，水解等转化使其与已知酸IX及相关酰胺相联系；文中另列丙二酸、丙二酸酯相关产物，并记有按所试路径脱水未成功的情况。作者据此讨论双CF₃取代羟基化产物的行为。[p649讨论及VIII–X结构式](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n102)、[p652实验段](https://archive.org/details/sim_russian-chemical-bulletin_1960-04_4/page/n105)

这里存在三项需要原刊校勘的差异：p649讨论写吡啶，p652 IX实验写哌啶；p649图示氯代乙酸酯，p652 VIII实验写溴代乙酸乙酯；p649涉及丙二酸酯，而p652 X实验的投料列项没有列出它。均保留原文差异，不能自行选定或补齐成可执行的现代实验协议。
