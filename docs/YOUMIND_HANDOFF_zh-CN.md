# YouMind 后续交付约定

GitHub 接收网站源文件和公开数据，YouMind 继续负责页面内容与展示更新。当前迁移不重写原页面，不把预览生成器或旧预览 URL 当作正式站点。

每次更新交付干净可解析的网页和 JSON 文件，以及修改文件列表、内容变化说明和实测记录；修订界面中的旧／新块不能直接作为落盘 JSON。保留现有相对路径、来源 ID、作者、定位、引用字段与科学边界。

导入 GitHub 时使用独立分支。先与上一版本比对，审查受保护 PFtB 页面和两份数据是否应变化，再经人工确认更新 `audit/site-manifest.json`；校验器不会自动改写基线来让检查通过。涉及科学表述的更新应保留证据和核校状态，不把界面验收等同于科学审定。

“百年诞辰”继续隐藏，启用时间由维护者明确决定。成果展示保持全面，不能用 F53 或某一条 AI 线索代替其他成果线。后续研究者已发表成果须按实际作者与时间列出；AI 推断、复算结果与原论文结论分开呈现。

更新后重新检查根路径、GitHub 仓库名前缀、证据回链、51 张来源卡和真实引用复制。Windows 11／WSL 2 与 GitHub Pages 的验收分别记录，未测项目保留未测。
