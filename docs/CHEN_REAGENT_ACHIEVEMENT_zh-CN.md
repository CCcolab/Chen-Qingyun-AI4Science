# 代表性学术成果：陈试剂与三氟甲基化

“陈试剂”对应氟磺酰基二氟乙酸甲酯（MFSDA，FSO₂CF₂CO₂Me）。连接式为 F–S(=O)₂–CF₂–C(=O)–O–CH₃，Me表示CH₃。它与酸型及TFDA硅酯分别建档。

1989年，陈庆云（Qing-Yun Chen）与吴生文（Sheng-Wen Wu）报道，该甲酯在碘化亚铜存在下作为三氟甲基来源，使芳基、烯基和烷基卤化物发生三氟甲基化。该成果的重点是试剂用途与合成方法开发，而不是把1989年写成这个分子的首次合成。
