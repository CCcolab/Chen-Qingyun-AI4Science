# 平台宗旨：纪念、学术成就与传承

现行说明日期：2026-11-14。

## 纪念陈先生，让读者理解他的研究与学风

平台以纪念陈庆云院士、介绍其生平与开拓性学术成就、传承其治学精神为首要目的。通过研究历程、原始文献、合作记录与育人故事，帮助公众和青年学习者理解陈先生与合作者面对过的科学问题、实际开展的工作以及留下的学术影响。

平台的内容主线是人物、生平、科学成就和学术传承。AI资料整理、早期成果复算与未来问题研究为这条主线服务，专业研究的阶段困难与技术细节放在对应记录中。

## 面向不同读者安排内容

- **公众阅读**：先看人物与研究历程，再读代表性科学问题、贡献及其背景。
- **学习与传承**：结合具体原文、合作关系和育人记录，理解提出问题、检查证据与训练学生的方法。
- **专业研究**：从专题进入原文定位、数据与分项研究记录，逐项查看方法、结果及局限。

首页与仓库主README承担人物、成果和阅读路径的介绍。详细计算记录、失败诊断、资源账本与工程资料保留在专业附录或研究目录，不占据平台的主要叙事。

## 历史成果与平台新增工作分别说明

| 内容身份 | 呈现依据与归属 |
|---|---|
| 历史已发表成果 | 按原论文、证书及其他原始材料，说明实际对象、年代、作者和合作贡献。 |
| 机构或文献中的学术评价 | 注明评价来源、语境与范围；“开创”等历史评价保留其原始归属。 |
| 平台AI资料整理与解释 | 说明原文定位、提取或核译范围及专业核校状态；关键缺口如实保留。 |
| 平台新增复算与现代模型 | 明确数值重放、量化计算及实验验证的不同身份，保存实际结果与限制。 |
| 未来研究问题 | 列为待查新、待论证的候选问题，不把设想或模型回答作为新发现。 |

历史已发表成果和机构评价依其原始来源呈现。平台新增AI解释、复算和候选计算的审阅状态单列，继续保留`review_required`及适用的`release_eligible=false`，不把平台计算资格作为陈先生历史成果成立与否的前提。

所有已发表工作保留原作者与合作团队的归属。后人的研究、采用、评价及平台新增分析也分别署明来源，不并为陈先生个人成果，不将资料整理称为国际优先权证明。

## AI研究的辅助位置

AI可用于原文检索与核读、名称和结构消歧、跨来源比对、数据提取、数值重放及问题整理。原文无法确认的文字、结构或数字保留疑问；AI核译和抽取不能代替专业原文核校。

A01（全氟酮化学：六氟丙酮与双酚AF）早期资料与A03（全氟叔丁基（PFtB）化学）原表数值重放是现有试点。A01（全氟酮化学：六氟丙酮与双酚AF）的双酚AF计量重建、衍生物物性复核和噁唑酮现代模型分别登记。现有M0模型记录属于阶段数值诊断，尚不能解释原文定性反应性差异；不据此宣称历史实验已复现、机理已确认或平台已有原创发现。

既有M0计算作为阶段档案保留，不自动续算。未来是否启动新计算或实验，须在具体科学问题、原始资料、先行研究及方法范围明确后另行决定。
