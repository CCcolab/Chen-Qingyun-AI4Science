# 双酚 AF：第 117491 号说明书的原始质量—收率账本重建

问题：说明书原图报告的 **98%**，能否由同一单例印出的有机原料质量、产物质量与目标化合物计量关系重建？这是已实际执行的历史数据数值重建，不是合成实验复现、机理验证或真实收率校正。

## 原始观察与结构依据

原说明书载于[公开镜像](https://poleznayamodel.ru/patent/11/117491.html)，原图 SHA-256 为 `f7482b83780bd86523763f2e0e6b1b980a90ad1141ffc6e91811242f6a630469`。本次 AI 核图读到苯酚 **12.2 g**、六氟丙酮 **11.2 g**、所称产物 **21.7 g** 和相对理论量的 **98%**。原图只报告名称，**没有画出结构式或印出分子式**。

依据完整化学名称作现代化学解释，目标为双酚 AF、候选分子式 C15H10F6O2。以下只采用这一身份下的净原子守恒：

`C3F6O + 2 C6H6O → C15H10F6O2 + H2O`

这不是原文绘制的反应式，也不表示反应机理已经验证。公开材料不复述催化剂、温度、时长或制备操作。原图仅留本机。

## 条件性重算结果

采用明确的现代近似原子量 H=1.008、C=12.011、O=15.999、F=18.998403163，假设印出的有机质量按原样使用、纯度为 1，且采用上述净计量关系：

| 数量 | 结果 |
|---|---:|
| 苯酚摩尔质量 | 94.113 g/mol |
| 六氟丙酮摩尔质量 | 166.022418978 g/mol |
| 目标产物摩尔质量 | 336.233418978 g/mol |
| 名义限制试剂 | 苯酚 |
| 名义理论产物量 | 21.793204507 g |
| 质量账本的表观收率 | 99.572323% |
| 与原报告 98% 的差 | +1.572323 个百分点 |

将三个一位小数的质量分别施加 ±0.05 g 的独立显示舍入扰动，得到表观收率约 **98.937413%–100.212459%**；把整数 98% 按 ±0.5 个百分点作显示舍入诊断，区间为 **97.5%–98.5%**。两者不重叠。所有质量角点上限制试剂仍为苯酚。

这些区间只是人为指定的显示舍入诊断，**不是实验不确定度或置信区间**；上界超过 100% 也不意味着实际化学收率超过 100%。完整结果还保留了按各原料单独作理论量基准的诊断，避免隐藏计量基准的选择。

## 科学解释与下一步

在当前假设下，印出质量和计量关系不能重建 98%。这不等于确定原作者计算错误，更不能据此推断造假。原件没有交代收率的具体纯度、理论量或其他修正基准；这些仍应作为待核问题。纯度修正的方向也不同：仅降低限制原料纯度会提高该条件性表观收率，不能随意用“可能纯度不同”解释任何方向的残差。
