# A01-OX-M1：从原始对照走向现代模型

研究问题：2-苯基-4-六氟异丙叉噁唑酮与非氟类似物的羰基加成／开环差异，能否在同一明确模型下得到解释？依据为1960年134(6)论文p.1368表1的定性对照及p.1369的作者解释；没有可供拟合的速率常数。

已依据原图登记一对分子图，六个 F 换为 H，保留共同骨架。原子映射是平台新增的计算标识：map 1为羰基O、map 2为羰基C，不等于原论文的环位编号。参见 [structures.json](structures.json) 和 [配对结构图](matched-pair.svg)。

SDF 为 RDKit ETKDGv3 起始几何；每个分子请求8次嵌入，RMS筛选后各保留1套，不表示已覆盖构象、得到稳定构象或完成量化优化。电子结构、频率与势垒计算均未执行。

起始输入的生成方法已保存为 `prepare_inputs.py`。可用 `python3 research/a01/oxazolone-model/prepare_inputs.py --output scratch/new-oxazolone-inputs` 生成新目录，保留分子图、随机种子、软件身份和文件指纹；不会覆盖现有输入。

核读表1后，选择苯胺作首个共同亲核体，介质按原文为苯；该项有同条件非氟类似物不反应的星号对照。水的记录实际在乙醚中，不能误设为均相水；过量氨有附加路径，醇反应另有催化例外。先固定构象、方法、介质和质子转移模型，再验证路径。比较每个守恒反应体系内的势垒及其差，不比较不同组成分子的绝对总能量。非氟类似物的开环产物只是模型对照，不是原文观察到的产物。

[协议草案](protocol-draft.json)仍为 `review_required`。原文的电子密度解释是推测；电荷描述符、起始几何或定性一致均不能单独证明实验机理。
