## 当前阶段

现行结果以[A01公开进展](../public-progress.v1.json)与[同一CF₃中心电子残差试验](cf3-center-terminal-scf-20261113-v1/REPORT_zh-CN.md)为准。该次试验仅将内部orbital目标由1e-9收紧至1e-10，正常extra-cycle保留，最终实际末次电子范数门槛仍为1e-9；核梯度预约及调用0。中心电子检查不授予完整曲率、势垒或机理资格。

前序A阶段五点重复性通过，局部互易差0.0014988911403202325 Eh/bohr²重现；旧B中心主循环第4轮曾短暂小于1e-9，末次检查为1.6225317681152e-9，核梯度前停止。B未取得梯度或互易差，不能说A、B都重现曲率误差，也不能排除SCF因素。完整阶段及原件指纹见[阶段摘要](../STAGE_HISTORY_20261113_zh-CN.md)。

CF₃完整Hessian虽已计算，但原始最大反对称误差未通过，0虚频诊断谱不能覆盖该失败。CH₃在此前受限模型及固定数值步长／网格内获得条件性局部极小支持；不证明全局最低、轨道稳定性或历史结构的唯一身份。

## 模型与科学边界

M0反应模型为一个指定底物加一个苯胺、苯连续介质、中性限制性闭壳层，无额外水、第二苯胺或酸碱。本轮对象仅是其中原26原子的孤立CF₃底物参照；PBE0／def2-SVP／ddCOSMO苯及原坐标、初猜保持。它与“苯作为反应物”的先行研究不同。

历史12.511659／29.531754 kcal/mol是所选非驻点几何相对各自“底物＋苯胺”的单点电子能差，不构成合格DFT势垒。各侧先在原子守恒体系内求差；不直接相减不同组成的绝对总能量，不用新参照松弛能更新旧势垒。

完整曲率资格闭合前不推进目标鞍点、IRC、势垒或机理解释。本轮没有统一零点、热、低频、标准态或浓度修正，不报ΔG‡或速率，也不把原文反应时长和分离收率转换成动力学常数。后续四个位移、中心核梯度与完整曲率另立协议和预算，不自动续算。
