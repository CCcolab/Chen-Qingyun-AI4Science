# A01（全氟酮化学：六氟丙酮与双酚AF）

A01（全氟酮化学：六氟丙酮与双酚AF）介绍陈庆云与合作者围绕六氟丙酮开展的实验化学研究：基本反应、六氟双酚A（双酚AF）制备，以及特定衍生物的结构鉴定与反应。历史成果依原作者及原始证据呈现，平台AI核译与新增研究另行登记。

## 原始学术成果与证据

[第一报学术贡献与原文证据](../../docs/A01_FIRST_REPORT_zh-CN.md) · [网站专题](https://cccolab.github.io/Chen-Qingyun-AI4Science/topics/early-fluoroketones/index.html#a01-first-report) · [结构化历史成果数据](../../content/a01-historical-achievements.v2.json)

- **六氟丙酮基本反应。** 第一报英译本647–653页全部影印图已核读，分别呈现醇加成与缩酮、有机金属加成与二醇、羟基酮裂解及β-羟基酸衍生转化。俄文原刊仍待核。
- **六氟双酚A制备。** 论文XI实例记载29g／90.5%／161–162°C；与第117491号说明书21.7g／98%分别登记。单体用途保留为作者提议；说明书、证书书影及论文署名各自呈现。
- **加成方向与结构判断。** 133卷原刊通过已知六氟缬氨酸、不同途径会合的腙等化学转化检查产物结构，原作者解释与观察分别呈现。
- **含氟噁唑酮的衍生反应。** 134卷原刊包含制备、开环与后续加成的网络，与双酚AF制备机制分开。

两篇Doklady论文共8页已作AI核读，专业核译及关键结构转录仍待签认。1983年EP0054227B1的原PDF前言明确回引1960年论文与二酚路线；这一技术引用不等于当代工业普遍采用调查。
