# A01：早期含氟酮与双酚 AF

研究目标：从原始研究的具体对象、观察和论证出发，利用 AI 辅助核译、图式辨识与竞争解释比较，逐步开展复算、验证和有依据的拓展。当前为原文与问题重建阶段；不把书目整理写成实验复现。

科学主线是六氟丙酮的反应性、指定含氟共轭体系的电子效应，以及双酚 AF 的分子结构与可测性质。先找到原文真正报告的观察，再以条件一致的模型与数据检验解释；题录和归属用于限定具体研究对象。

## 先回答五个科学问题

1. **两篇 1960 年论文各研究什么？** AI 逐段核译、图文对齐，建立独立的化学对象身份。原图、命名或不同版本冲突时保留未定，不自动合并结构或生成计算输入。
2. **双酚 AF 历史样品的身份凭什么成立？** 提取原件实际给出的表征，区分结构支持、异构体辨识与仅能说明纯度的证据。现代数据库的名称或结构不能反向证明当年样品或成果归属。
3. **原有电子效应解释支持到哪里？** 把原始观察、原作者解释和平台的替代解释分栏；现代计算必须对准原文实际可比较的量，不能用单个电荷或轨道指标直接验证反应或普适顺序。
4. **异常沸点的解释能否独立检验？** 既有传记登记涉及反应样品与乙醚的恒沸物解释。先核样品、组成、压力和原始记录；没有这些数据，不能由单分子能量“验证恒沸物”，也不能换成六氟丙酮本体的沸点。
5. **含氟桥基与可测性质之间有什么可检验关系？** 后续可选择具备同条件实验基准的双酚 A／AF 配对性质，例如解离性质，开展模型比较。须先查新、明确分子状态和溶剂；单体计算不能直接推出树脂耐热性、工艺效果或工业性能。
