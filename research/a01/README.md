# A01：早期含氟酮与双酚 AF

研究主线是六氟丙酮的反应性、指定含氟共轭体系的电子效应，以及双酚 AF 的结构与可测性质。用原页中的实际观察约束 AI 分析，再开展可追溯的复算和模型再检验。

## 当前科学进展

- 已取得并核读两篇1960年论文的八页原文，以及117491号发明人证书的一页说明书扫描。该扫描不是授予证书正页，未显示1959年落款。
- 已提取分子图、物性与表征数据，并分开记录原始观察、原作者解释和AI推测。详见[原始材料核读与研究结果](PRIMARY_READING_20261111_zh-CN.md)、[关键短句核译](KEY_PASSAGES_zh-CN.md)与[结构化提取](primary-extracts.v2.json)。
- 首项实际研究为[双酚AF收率证据重建](bisphenol-af-yield/README.md)，已执行；并行完成[折射性质重建](molar-refraction/README.md)。两项均保留待解释残差，不修正原数或裁定原因。
- 首项现代模型问题选为[CF3/CH3配对噁唑酮的羰基反应性与开环](oxazolone-model/README.md)。配对结构和起始坐标已准备，电子结构与势垒计算尚未开展。

## 科学判断的范围

折射度和收率账本重建是原始数值证据再分析，不能代替新实验、结构唯一性鉴定或量化机理验证。原文中的中间体、构象与电子效应解释，须保留其推测程度。

下一阶段先追查收率和折射度残差的计量或数据约定，再固定配对模型的构象、溶剂、质子转移、方法和可证伪判据。不同条件的反应时长与分离收率不拟成速率常数；单个原子电荷不作为机理证明。
