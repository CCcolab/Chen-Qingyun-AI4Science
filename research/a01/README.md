## 当前科学进展

本轮入口为[公开进展v2数据](public-progress.v2.json)、[v2接口说明](PUBLIC_PROGRESS_V2_INTERFACE_zh-CN.md)及[五点精度诊断报告](oxazolone-model/cf3-tight-gradient-diagnosis-20261113-v1/results-v1/RESULTS_zh-CN.md)。同一CF₃底物中心及C6-y／C10-y四个位移已实际完成，五点电子终态、身份和完整核梯度均合格。内部SCF能量／orbital目标为1e-12／1e-10，最终实际末次orbital范数门槛仍为1e-9；完整精度以实际机器摘要为准。[原v1中心电子记录](public-progress.v1.json)保持不变。

本轮两列互易差为`0.0014977575105072183 Eh/bohr²`，仍超原绝对门槛约14.98倍。相对旧A有符号变化`−1.1336298130141913e-6 Eh/bohr²`，小于`4e-5`重复性传播对照尺度，因此本次未解析出SCF精度影响，不能排除SCF因素或确定唯一根因。FD1两列通过；FD2仅作对角二阶诊断，C6-y未达容差、C10-y通过。

CF₃完整曲率与局部极小值资格仍未闭合，本轮没有新的完整频率／虚频数，也没有合格DFT势垒排序或机理解释。CH₃保留原受限模型和既定数值判据下的条件性局部极小支持，不等于全局构象最低、轨道稳定性或实验验证。
