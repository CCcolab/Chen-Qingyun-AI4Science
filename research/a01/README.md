# A01：全氟酮化学早期研究

专题为“全氟酮化学早期研究：六氟丙酮反应与六氟双酚A（双酚AF）制备”。陈庆云及合作者的原始化学成果以原论文和说明书为依据；本平台开展原数据复算和现代模型再检验。所有新增分析保持 **`review_required`、`release_eligible=false`**，不当作具名审定结果或新实验。

## 当前科学进展

现行入口为[公开进展数据](public-progress.v1.json)、[接口说明](PUBLIC_PROGRESS_INTERFACE_zh-CN.md)及[本轮中心电子试验报告](oxazolone-model/cf3-center-terminal-scf-20261113-v1/REPORT_zh-CN.md)。本轮只检查同一CF₃中心在内部orbital目标1e-10下的真实末次电子残差，最终门槛仍为1e-9；实际状态及全精度数值以已归档机器摘要为准。核梯度调用0，后续位移和完整曲率另列协议。

当前CF₃完整曲率资格仍未通过；SCF精度对互易误差的影响和根因仍未知，没有合格DFT势垒排序。CH₃保留原受限模型和既定数值判据下的条件性局部极小支持，不等于全局构象最低、轨道稳定性或实验验证。
