# A01-MR-T1：原文折射性质的独立重建

科学问题：1960 年原刊给出的折射率、相对密度和分子式，能否在明确质量约定下重建所报摩尔折射？原刊“found MR”“计算 MR”和本轮 Lorentz–Lorenz 重建分别记录，不互相替换；MR 不表述成另一次直接测得的原始观测。

原研究：陈庆云、N. P. Gambaryan、I. L. Knuniants，1960，133(5):1113–1116；数据位于 p.1115–1116，来源登记 CQ-H12。参见 [Math-Net 原文](https://www.mathnet.ru/rus/dan23922)。本轮数值重建另列身份，不改原作者归属。

已逐图提取 I–V。主比较使用同为 20°C 的 I、V：整数质量约定下，I 重建为约 53.744，与原刊 53.74 相容；V 约 52.282，原刊为 54.90。两套质量约定和指定显示舍入均不能解释 V 的全部残差，但原因未定，不能据此判定原刊排印或实验有误。

IV 的折射率在 19°C、相对密度在 20°C，结果仅为混合温度输入的条件值；原文缺温度系数，未校正。III 的 MR 行漏印 N，而结构和下一元素分析式含 N，原文异文保留。

密度采用 `rho ≈ d20_4 × 1 g/cm³`。±0.00005 只是四位小数的独立显示舍入诊断，不是实验误差或置信区间。原刊未列出“计算 MR”的具体方法与常数，本轮不代为确定或补造。

原刊的 MR 未在该段另印单位，本轮按通常的 cm³·mol⁻¹ 解释，与 [IUPAC 摩尔折射定义](https://goldbook.iupac.org/terms/view/M03979)对应；整数质量是本轮的敏感性约定，不是对原作者所用常数的认定。
