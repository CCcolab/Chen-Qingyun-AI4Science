## 代表性学术成果：陈试剂

氟磺酰基二氟乙酸甲酯（MFSDA，FSO₂CF₂CO₂Me）被称为“陈试剂”。1989年，陈庆云与吴生文报道其在碘化亚铜体系中的三氟甲基化用途，使这一甲酯成为向有机分子引入三氟甲基的合成工具。2018年后续原论文题名直接使用“Chen’s reagent”，展示了这项成果的命名与研究接续；后续改进保留实际作者归属。

陈试剂列入A06（磺酸酯、二氟卡宾与三氟甲基化）成果线，与同线的磺酸酯、二氟卡宾研究相联系。甲酯的既有分子身份、1989方法开发和后续研究分别呈现。

## 早期学术成果：全氟酮化学

陈庆云与克鲁扬茨、甘巴里扬等合作者围绕六氟丙酮开展实验化学研究。1960年《Fluorinated ketones》第一报的英译本全文记载了多类基本反应、六氟双酚A及相关二酚的制备与鉴定。第117491号发明文书保存另一项制备记录与单体用途提议。另两篇原刊展示了通过加成方向、化学转化和衍生物比较来判断结构的研究方法。
