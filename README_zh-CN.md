# 陈庆云院士早期研究：AI 辅助复现与拓展首期包

研究整理日期：2026-11-11。版本：0.1.0，研究候选。

本包已经实际运行一项直接绑定陈庆云、蒋锡夔、陈秉启、梁梦兰 1966 年原论文的任务：**重放表 1 的三个碘代物、两种给体溶剂的位移算术，并检查换成波数尺度后的名义顺序与敏感性。** 它是数值重放，不是新的实验、光谱曲线拟合、量子计算或普适诱导效应模型。

AI 在本次工作的作用是核读扫描表、核对化学实体、提出尺度与扰动对照、检索已有工作并整理研究合同；固定的 Python 程序执行算术和输入资格检查。运行本包无需模型账户、API 密钥、联网或第三方 Python 库。在线模型服务、交互式后台、量化计算队列尚未实现，也没有部署到网站或 GitHub。

```bash
python3 -m unittest discover -s tests -v

```

默认输出写入 `results/`；也可执行 `python3 -m chen_research --output scratch/replay`。保留默认输入时，数值结果及来源／代码指纹应与已交付结果一致。

本次实际运行环境见 `results/environment.json`。**Windows 11／WSL 2／Ubuntu 尚未实测**，不能用本次 Linux 运行记录替代。

## 阅读与使用边界

1. 原论文的三种实测对象为 n-C3F7I、i-C3F7I、t-C4F9I。不能把 n-C3F7I 换成 C2F5I，也不能补造 CF3I 的测量。
2. 原表以 C6H14 为基准；本包保留该原始记号，未凭分子式进一步指定异构体。EtOH 和 Et2O 是给体溶剂，B 不是苯。
3. 原表未给本次所需的测量不确定度。±0.05 nm 仅是按一位小数通常舍入作的扰动诊断，不能称作实验误差或置信区间。
4. 三碘代物的数值关系不能单独验证四基团的普适顺序、游离阴离子、亲卤机理或现代应用性能。
5. 现代研究属于各自作者。研究路线图没有把“本轮未检出完全相同工作”写成首次发现或新颖性结论。
